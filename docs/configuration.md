# Configuration Guide

## Overview

The Theme Manager plugin provides theme configuration for Open edX using Tutor.

## Available Themes

| Theme | Primary Color | Hex Code |
|---|---|---|
| Indigo | Indigo Blue | `#15376D` |
| Pink | Pink | `#E91E63` |

## Configuration Variables

| Variable | Default | Description |
|---|---|---|
| `MYFIRSTPLUGIN_DEFAULT_THEME` | `indigo` | Default theme setting |
| `INDIGO_PRIMARY_COLOR` | `#15376D` | Indigo primary brand color |

## Switching Themes

Switch to Pink:

```bash
tutor themes set pink
