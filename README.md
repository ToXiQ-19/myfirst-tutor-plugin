# My First Tutor Plugin

A simple custom Tutor plugin developed for Tutor 19.x.

## Features

- Demonstrates how to create a custom Tutor plugin.
- Registers a custom Tutor configuration variable.
- Uses Tutor's plugin hook system.

## Requirements

- Python 3.9+
- Tutor 19.x

## Installation

Clone this repository:

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>
cd myfirst-tutor-plugin
pip install -e .
tutor plugins enable myfirstplugin
